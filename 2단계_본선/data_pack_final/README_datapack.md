## 사용 안내

**인코딩**

* CSV: UTF-8 with BOM — Excel에서 바로 열립니다.
* 파이썬: `pd.read\_csv(path, encoding="utf-8-sig")`

**금액 단위**

* `06`, `07`의 금액 열은 **백만원** 단위입니다. (예: `2140.0` = 21.4억원)
* 총 예산 11,800 = 118억원

**주차(week) 기준**

* week 1 종료일 = 2026-01-09 (금), 이후 매주 금요일. week 33 = 2026-08-21.
* 스프린트는 2주 단위 S01\~S18. S01 시작 2026-01-05, 현재 **S17** 진행 중.

**교차 참조 키**

* `req\_id` : `03` ↔ `04`
* `benefit\_id` : `02` ↔ `03` ↔ `04`
* `decision\_id` (DEC-nn) : `12` ↔ `17`(회의록) ↔ `18`(메일)
* `cr\_id` (CR-nnn) : `05` ↔ `17`
* `risk\_id` (RSK-nn) : `11` ↔ `17`
* `week` : `06` ↔ `07` ↔ `08` ↔ `13`
